1Spesifikasi Produk

1.1 Apa ini

GoldPulse adalah asisten analisa harian XAUUSD (gold) berbentuk aplikasi web mobile (PWA). Setiap pagi kerja sistem memeriksa chart, event ekonomi, dan statistik pola historis, lalu memberi satu rekomendasi jelas — masuk (entry), tunda (tunggu), atau diam (netral) — lengkap dengan level entry, batas rugi, dan target. Setiap rekomendasi kemudian dinilai jujur terhadap pergerakan harga aktual dan hasilnya ditampilkan terbuka, termasuk saat sistem salah.

1.2 Prinsip produk (tidak boleh dilanggar)

1. Jujur secara statistikConfidence = win-rate historis pola (out-of-sample diprioritaskan). Tidak ada janji akurasi; hit-rate nyata ditampilkan apa adanya, termasuk yang buruk.
2. Web-based onlySemua informasi hidup di web/PWA. Tidak ada notifikasi apa pun (Telegram, email, push) — user membuka kapan pun perlu.
3. Serverless & gratisTanpa VM/server: GitHub Actions sebagai compute, JSON di repo sebagai database, static hosting untuk frontend. Semua tools tier gratis.
4. WIB, H4 duluSemua waktu tampil dalam WIB (UTC+7), penyimpanan UTC. Analisa utama timeframe H4, pemicu H1.
5. Sumber tervalidasi sajaFundamental hanya event 3★ AS (Trading Economics) dan berita wire/whitelist (Reuters dkk) — tanpa opini, tanpa media sosial.
6. Aman secara defaultNol secret di frontend; kredensial hanya di .env lokal (gitignored) dan GitHub Secrets. Bukan saran finansial — disclaimer selalu tampil.

1.3 Target pengguna

  • Trader ritel XAUUSD yang ingin disiplin aturan, bukan insting.
  • Butuh ringkasan cepat di HP (tab Ringkasan, bahasa awam, <1 menit bacaan) sekaligus detail teknis bila ingin mendalami (tab lain).
  • Selalu di HP → dirancang mobile-first, bisa di-install ke home screen (PWA), offline-ready.

4How-To (Panduan Operasional)

4.1 Setup awal (sudah selesai — untuk dokumentasi/ulang)

  1. Clone repo, buat .env berisi TWELVEDATA_API_KEY=... (file ini di-gitignore, tidak pernah di-commit).
  2. Di GitHub → Settings → Secrets and variables → Actions → tambah secret TWELVEDATA_API_KEY.
  3. Jalankan manual sekali: workflow Backfill (isi 3 tahun), lalu Fundamental dan Analisa Harian.
  4. Import repo ke Vercel: Root Directory = web (preset Vite, build otomatis). Deploy.
  5. Buka URL di HP → Add to Home Screen (PWA ter-install).

4.2 Penggunaan harian (sebagai user)

  1. Buka app → langsung mendarat di Ringkasan: baca verdict 1 menit (ada/tunda/diam peluang + angka risiko).
  2. Mau detail? Overview untuk chart (scroll = zoom, tarik = geser ke sejarah), Daily analysis untuk level & alasan, Fundamentals untuk event/berita.
  3. Serius verifikasi klaim sistem? Backtest lab (statistik pola) + panel Deep-dive PDF (laporan mingguan).
  4. Spot harga di kartu update tiap 30 detik; data lain refresh tiap 10 menit atau tarik-refresh browser.

4.3 Pemeliharaan (kalau ada masalah)

GejalaPeriksa / solusi

4.4 Keamanan — aturan tetap

  • API key hanya di .env (gitignored) lokal dan GitHub Secrets. Tidak pernah hardcoded, di-commit, ditulis ke data/, atau masuk frontend.
  • Frontend hanya memuat URL publik: raw.githubusercontent (data), XAUS.com (spot tanpa key), Google Fonts.
  • Repo public = semua yang di-commit itu publik permanen — review sebelum push (aturan: push hanya atas perintah owner).
  • Link eksternal di app memakai rel="noreferrer"; input user (catatan analisa) hanya di localStorage perangkat.

4.5 Batasan sistem (yang perlu diingat)

  • Backtest tidak memodelkan spread/slippage/swap — angka nyata selalu lebih rendah dari angka backtest.
  • Win-rate pola dengan sampel kecil (n < 30) tidak signifikan secara statistik.
  • Data kalender/berita seefektif sumbernya; rilis mendadak (geopolitik) bisa datang tanpa jadwal.
  • Sistem memberi probabilitas, bukan prediksi — 45% berarti lebih sering meleset, dan itu ditampilkan jujur.
